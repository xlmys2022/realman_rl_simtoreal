## 先验检查与实际目标分布

修改前在原模型上，每个半径采样250个3mm到外半径之间的候选，使用原IK、home ±5°、限位和路径检查：

| 候选外半径 | 通过 | 拒绝 |
|---|---:|---:|
| 5mm | 248/250 | 2个关节演示边界拒绝 |
| 10mm | 158/250 | 92个关节演示边界拒绝 |

因此默认采用5mm，没有扩大关节、命令区域或安全阈值。采样方法：

1. 只使用Gymnasium的 `self.np_random`，由 `super().reset(seed=seed)`管理。
2. 正态方向向量归一化，半径立方均匀采样，产生体积均匀球壳候选。内半径为 `(success_threshold+target_radius)/2`，默认3mm；外半径默认5mm。因此初始位置不会已经成功。
3. 目标旋转始终是home朝向，IK从home初值求解；复核模型限位、home ±5°、理论位姿及原51点离散路径碰撞检查。
4. 通过才接受；否则记录拒绝类别并重试。默认最多64次（可设1–1000）；耗尽抛RuntimeError，episode保持不可step，不能无限循环或返回未验证目标。

reset仍只通过官方keyframe重置状态。采样的FK/IK与碰撞探针使用独立数据，不推进时间或赋值运行中的qpos。`reset(seed=s)`重复相同目标；之后不传seed的reset会继续同一随机序列。评估分别使用种子0–99，以便两策略得到完全相同的100个目标。

实际目标相对home的分布：

| 数据 | 范围 |
|---|---|
| X | -4.654583至+4.825952mm |
| Y | -3.762540至+4.566705mm |
| Z | -4.184603至+4.434721mm |
| 距home半径 | 3.023015至4.996428mm |
| 八象限数量 | +++:12，++-:14，+-+:11，+--:9，-++:12，-+-:14，--+:16，---:12 |

这是通过检查后的**条件分布**，不是完整或均匀的机器人工作空间。IK静态可达也不表示任意高速命令序列都满足动态朝向保护。

## 奖励漏洞、方案与重算约定

原奖励的具体反例：相同home、目标、物理模型、时间限制和10mm动作尺度，成功策略每步输入0.1的+X动作，故意失败策略第一步输入[1,1,1]。

| 奖励 | 成功轨迹（6步） | 故意越界（1步） |
|---|---:|---:|
| distance，单位m | -0.0185347377055 | -0.005 |
| safe_dense，无量纲 | -0.926736885275 | -201.25 |

默认1mm动作尺度也有问题：静止200步超时回报-1.0，连续+Y命令第5步触发关节演示边界，回报约-0.02529，比长时间未完成的安全轨迹更高。不能把这种提前终止优势留给训练器自行处理。

设H=max_episode_steps（默认200），d为实际末端到当前目标的距离：

`r = -min(d / 0.020m, 1) - (H+1) * is_safety_failure`

20mm取自原10mm实验命令球的直径，提供固定长度尺度；截断使成本在[-1,0]，不把实际跟踪状态假设为严格处于命令球内。除20mm以外没有多个经验权重或成功奖金。越接近目标通常奖励越好；正常距离超过20mm时成本饱和。

对**未折扣、至多H步**回报，任何无安全失败episode总回报≥-H，任何安全失败episode总回报≤-(H+1)。惩罚由这个上界推导，不为某个成功率拟合。它消除未折扣评估中提前失败的优势，但不保证所有不同折扣因子、不同轨迹之间的全局排序；未来训练需审查gamma、horizon及大惩罚引起的方差。超时不另加失败惩罚。

step先构造info，再把同一个info传给compute_reward。safe_dense必须提供布尔 `is_safety_failure`，支持单个dict、dict列表/数组或含布尔数组的dict。缺失或非法标记明确报错，不会静默漏算惩罚。distance模式保持旧的无info调用和米制单位。

`is_safety_failure`来自该物理/命令转移的安全检查，与desired_goal无关；重标目标时仍保留。compute_reward只用新的achieved/desired位置和此标记，不使用旧info中的is_success、distance或success原因。若新目标恰好等于实际位置，安全失败依然受罚。批量与step奖励一致性已测试。

## 终止机制与观测一致性

本次保持原终止语义，没有边界投影、忽略IK失败或放宽阈值：

- 成功：实际距离≤1mm，terminated=True。
- 命令区域超界、关节命令/实际限位、局部IK失败、保守reach bound超界、碰撞、速度/朝向、数值或驱动力异常：terminated=True，独立原因及安全失败标记。
- 达到最大步数：truncated=True、原因time_limit，无安全失败标记。成功/安全失败仍优先于同一步超时。
- 预检拒绝不提交参考或执行无效关节目标；物理阶段可提前停止。真实碰撞、异常力矩、非有限状态的保护沿用原实现。

命令10mm球与home ±5°是局部实验约束，不是实物工作空间或厂家额定限位。随机策略的67次joint_limit均发生在最后一次物理步之前（该步推进0次），是关节命令范围拒绝，不能报告成实际机械臂穿过硬限位。

随机策略探索频繁触边，未来可以对“外向命令增量”单独比较拒绝并保持或命令球投影，但必须发生在IK之前；非法最终IK关节解仍需拒绝。当前规则策略在原机制下100/100成功，没有证据要求取消终止保护，因此本次未实现这些替代机制。

reset、step、success、failure、timeout均检查27维观测有限且属于空间，`observation[15:18] == desired_goal-achieved_goal`。数值故障仍返回明确标记的旧有限快照，不修复实际运动状态。

## 无训练策略与配对结果

随机策略：独立均匀采样整个Box(-1,1)，策略随机数与目标随机数分离。

规则策略只读取公开观测，设p为实际末端、c为命令参考、g为目标：

`delta = (g-p) - (c-p) = g-c`

将delta按action_scale归一化，动作向量范数限制为0.25，转换为合法float32动作后，仅通过env.step运动。默认每步最多0.25mm；参考到目标后输出零增量，等待位置执行器追上。它借助已有PD完成物理闭环，不是额外的末端闭环控制器。

先前20集试验使用较大分量动作，规则仅19/20成功。种子1目标为[+1.792955,+4.262708,+1.714369]mm；各步均触发关节指令变化率限制，实际朝向逐步偏移至1.020345°，被原1°保护终止。该记录保留在pilot文件中。减小规则步幅，给耦合腕部运动留出余量，没有修改控制器、关节速度、力矩或朝向阈值。最终100集包含该失败种子。

## 训练条件与限制

目前具备进行**局部、固定模型、无视觉的小规模训练实验**所需的随机目标、标准接口、独立安全机制、可重复基线及墙钟数据。使用随机模式默认safe_dense；兼容distance模式仍有已证明的奖励漏洞，不应直接用于训练。

100/100规则成功只对这100个目标和当前初始状态成立，不证明所有采样目标、任意初态、任意策略或真机均安全/可达。随机策略89%的非成功率、较大终止惩罚的回报方差、严格实验边界、约65步/秒串行吞吐及动态控制延迟都应在未来训练时监测。成功仍仅按1mm距离，不要求速度归零或驻留。

HER尚未实现。重标目标必须更新desired_goal、observation[15:18]、距离、成功与成功终止条件；保留安全失败标记和独立超时信息，使用相同环境horizon计算奖励，不能直接沿用旧成功终止标签。当前Dict和compute_reward接口不等于完整HER兼容性。

临时ee_site、真实型号/TCP、厂家与MuJoCo模型差异、仿真质量参数依赖和离散碰撞预检的局限均保留。本次没有训练器、网络、Replay Buffer、HER实现或新控制/模型。
