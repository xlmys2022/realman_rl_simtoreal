# 03-C2：动态物体接触、夹持与释放验证

验证日期：2026-11-07。全部计算使用realman_rl环境：Python3.11.17、MuJoCo3.17.0、NumPy2.4.6；没有安装新依赖。pip check通过。无厂家连接、运动指令、训练或ReachEnv接口变化。

## 结论和范围

**当前未标定EG2-4C2模型能够通过真实接触和摩擦夹住本实验的10g方块。** 采用原执行器/增益/关节轴/连杆参数，慢闭合后实际开口约20.001mm；通过机械臂执行器沿支撑法向抬升5mm，方块离台约4.697mm，在无台面接触的情况下保持2秒。随后降近台面并缓慢张开，方块在重力下落回台面。

这不是实物性能验证。质量94.2992g与产品231g不符、66.217mm模型行程与70mm产品行程不符、8mm安装变换和传动/接触/执行器参数均未经实物标定；这些已知差异全部保留。低摩擦和30g案例未通过稳定夹持，按原mimic/速度保护停止，未放宽保护或增大增益。

## 物体、支撑与初始化

方块：20×20×20mm，基准质量0.010kg，重物对照0.030kg，均为实验选择。均匀立方体主惯量 `I=m*s²/6`，分别为6.6666667e-7和2e-6 kg·m²；质心为几何中心。target_free为真正freejoint，没有weld、connect、跟随约束、外力注入或重力补偿。

物体初始中心由home、20mm几何开口下的左右pad site中点计算，约为世界[0.0826978932,-0.0002678182,1.1937314908]m。物体坐标轴与实验夹爪mount轴一致；四元数wxyz约[0.965923623,0.000207089,0.258826058,-0.000764233]。场景home keyframe存储初始化位姿，运行时只用mj_resetDataKeyframe初始化。初始化后物体位置/姿态仅由mj_step演化。

支撑台为固定18×40×6mm窄台，与物体轴对齐；其顶面在方块下方10mm。它是约30°的**倾斜支撑面**，不是水平桌面，也不是物体约束。尺寸留出两侧夹指间隙。世界重力始终[0,0,-9.81]m/s²，时间步2ms、implicitfast，其他原场景设施保留。

目标—指垫滑动摩擦系数为0.7（低摩擦对照0.05）；目标—支撑台为1.0。显式pair的5维friction为[μ,μ,.005,.0001,.0001]，condim=3，因此仅法向和两个滑动分量起作用，未添加接触黏附或扭转/滚动夹持。显式pair避免“只降低某个geom摩擦，但被max混合规则覆盖”的错误。pair solref=[.006,1]；指垫solimp=[.95,.99,.001]，支撑台[.999,.9999,.001]。这些是明确的实验接触参数，不是厂家标定值。

## STL与碰撞代理依据

逐三角面读取原4C2_Link5/6.STL：内向齿顶在局部x=±17.7mm；各有十条分开的矩形齿顶，总面积306mm²。射线截面进一步确认：真实齿槽最低前表面约x=±17.3mm，槽深约0.4mm；x=±10mm、面积270mm²的平面是指片背面，不能当成齿槽底。生成器从原三角形获取齿顶Y/Z边界并核对面积，再从内向表面提取两段保守槽底覆盖区：Z[-5,10.5]mm/Y[.4,11.6]mm及Z[10.5,28.5]mm/Y[-3,15]mm。槽底面取原内向面最小|X|，不向原表面外增加材料。

每个平面生成0.5mm厚的box层，厚度全部向原实体内部延伸，接触前表面不外移。每侧12个（十条齿顶、两段槽底），共24个；mass=0，原body显式惯量不变。视觉STL完整保留。代理仅用于指定目标接触；原指片STL凸包仍用于机器人内部、支撑台以及普通外物的碰撞。

独立场景的过滤位：原普通机器人/台面1/1；左右指片旧凸包4/5；薄层8/2；目标2/9（contype/conaffinity）。目标改用薄层接触，机器人—台面及左右指片等原接触能力仍保留。没有全局关闭接触。hull诊断模式删除代理显式pair后恢复原凸包—目标pair，避免显式pair绕过mask造成错误对照。

凹槽反例是独立forward诊断：将0.1mm探针方块初始化在左指局部[17.5,6,18]mm的真实齿槽空隙。原STL三角面射线证明探针Y范围[5.95,6.05]mm内真实前表面约17.3mm，探针最内侧X=17.45mm仍在实体外；旧凸包却错误报告约0.250013mm穿透，接触位置局部x约17.575006mm，薄层无接触。早期x=14mm探针实际上在STL实体内部，其所谓“空隙”解释已撤回，不计作有效几何证据；新测试独立核验原三角面射线和各代理内部采样点，防止重复此错误。该诊断不推进物理，也不被当成20mm方块夹持结果。20mm方块能同时跨越多个齿顶，正常夹持时两模型都能接触；不能仅以大方块夹住便断言旧凸包几何正确。

原eg2_left_pad/right_pad site位于X=±17.7mm、Y=6mm，实际Y=6mm落在齿槽中，因此继承的“pad”标签应理解为齿顶包络上的名义宽度参考，不是该点真实STL接触面。开口仍表示两侧齿顶包络的间距；真实接触识别按geom/body，不用site点冒充接触点。03-C1来源记录原字节保留，此处补充该解释修正。

局限：薄层描述内向齿面，不是全指片非凸实体分解；槽底采用保守平面，未完整复刻0.4mm深槽的曲面齿侧壁与所有边缘的目标碰撞，不能据此验证任意方向高速撞击或任意形状抓取。其他外物仍使用原凸包。后续通用抓取前需更完整的碰撞分解/标定。

## 接触分类与保护

只对明确geom及body所属关系识别的接触设置局部容许穿透：

- left_pad_target、right_pad_target：各≤0.3mm，20mm方块边长的1.5%；box层厚0.5mm，正常低速接触不应穿透该层。
- target_support：≤0.2mm，边长的1%。允许软接触的小数值压入，并不允许无界压穿。
- robot_support、robot_internal_or_other、target_other：保持原≤0.1mm，包括机器人—支撑台和异常夹爪内部接触。

这些上限是本实验的保护标准，不是拟合实物材料。正常案例实测全程最大穿透0.041559mm，离台阶段最大约0.001241mm；安全释放全程最大0.102382mm（目标—支撑台瞬态），均小于相应上限。原Gripper(model,data)空载接口仍对全部接触使用0.1mm，不受此可选策略影响。

继续检查：机械臂原关节限位/30°每秒速度界、夹爪原关节限位/1.001rad/s容差、mimic残差≤0.001rad、全部数据及接触几何/力有限、MuJoCo warning、外力注入、全部机器人总驱动力通道。目标物体线速度≤1m/s、局部角速度≤30rad/s是本低速实验的额外保护。

## 控制顺序和力数据

每个50ms周期：合法六轴目标验证（home±5°、原限位）→每周期最多0.5°参考变化及smoothstep→更新夹爪参考（原0.5rad/s slew上限）→循环25次mj_step。每个物理步只积分一次；步后执行原ForceMonitor、夹爪主/从动总驱动力、状态/分类接触检查，再采样接触力，最后mj_forward并复查。原run_segment、advance_control_cycle和Gripper.step仍可单独使用，不能把各自25步相加称为一次25步周期。

闭合和释放在6秒内对关节参考再做smoothstep，避免高速接触。夹爪kp=.05、kv=.002及原阻尼/限幅不变。零开口命令仅产生有限伺服预载；方块阻挡后实际开口保留约20mm，不再要求闭合到零，也不改qpos消除跟踪误差。

[MuJoCo官方接触力说明](https://mujoco.readthedocs.io/en/latest/programming/simulation.html)：mj_contactForce返回接触系的3维力及3维力矩，第一轴为法向。`contact.frame`三行是世界系中的接触轴，因此 `F_world_on_geom2=frame.T@F_contact`；若目标为geom1则取反。本次保存左右法向力分别之和、切向力模长分别之和，同时保存各接触向目标施加的世界力，绝不把某一接触分量叫作世界Z力，也不把两侧法向数值相加命名为标定夹持力。

每2ms保存标量；每50ms及新接触类别第一次出现时保存详细geom/body、接触位置、接触系六维力和世界系物体受力。力来自刚完成的mj_step、尚未刷新缓存；qpos/qvel是积分后状态，接触几何对应该步力计算时刻。当前几何/指垫位置计算使用独立MjData，不污染实时力缓存。freejoint qvel的前三项为世界线速度，后三项为物体局部角速度，参见[官方坐标说明](https://github.com/google-deepmind/mujoco/blob/main/doc/overview.rst)。

## 对照结果（单次确定性实验，不是统计成功率）

A，normal：10g、μ=.7，12.500s完整执行；离台保持通过。最终左右法向力0.151828/0.200902N，切向模长和0.033697/0.051197N；台面法向力0。物体距支撑面4.696769mm，位置世界[0.085126965,-0.000285639,1.197762071]m；末端2秒保持期间相对夹指滑移累计约0.137072mm，最后0.5秒约0.033951mm，**并非完全无滑移或无限期保持**。末时线速度约[-.03413,-.000043,-.05903]mm/s。实际开口20.000929mm，命令0mm，差20.000929mm来自物体阻挡。

B，no_close：10g、μ=.7，开口60mm，12.500s完整执行。左右接触力均0，台面法向力约0.08496N，离台间隙近0。即使机械臂完成抬升，物体仍留在台上，不判夹持成功。

C，release：先重复A的抬升和2秒保持，再由原IK/执行器下降至名义1mm法向高度（实际物体间隙0.582mm），6秒缓慢张开至60mm，观察1秒；21.500s完整执行。最终两侧力为0，台面法向力约0.08496N，开口约60mm，物体自然回到台面；没有物体跟随约束。mimic残差峰值0.000847rad，未触发保护。

D，low_friction：仅指垫—目标μ降至.05，质量10g、台面摩擦不变。6.434s闭合阶段触发mimic残差0.001195934rad保护，终止，未进入离台保持。最后安全记录左右法向0.097919/0.149450N，切向0.004896/0.007472N，已接近低摩擦滑动边界；物体仍由台面支撑。该案例不能用来宣称已完成“离台后滑落”全过程，直接失败原因是接触载荷下mimic残差，低摩擦切向能力也明显不足。

E，heavy：质量30g、μ=.7，8.814s抬升初期触发夹爪速度1.075132rad/s保护；同一失败状态mimic残差约0.001515rad，停止，未通过离台保持。最后安全记录左右法向0.135954/0.260524N，夹指支持不稳定；不能把台面上短时停留称为夹住。此时伺服没有达到硬力矩上限，不能把失败解释为真实EG2-4C2最大夹持能力。

补充hull：旧凸包同样完成12.500s，但末时离台间隙3.267297mm、2秒相对滑移约0.879507mm；薄层约0.137072mm。两者接触点数量和切向力分布不同，薄层在本案例减小滑移，但没有以成功结果证明其已是准确实物接触模型。

## 力矩、补偿与稳定性

正常案例主夹爪伺服约-0.013119N·m，补偿路由后的总驱动力约-0.010767N·m；全程峰值0.010782N·m，远低于±0.2N·m硬限幅（没有饱和）。五个从动joint也逐步验证补偿后总驱动力与各自±1N·m限幅，没有独立伺服/外力旁路。六轴峰值总驱动力约[.003837,2.337627,4.917645,.095803,.744232,.001698]N·m，对应上限[60,60,30,30,10,10]，饱和步数0。

正常/释放案例夹爪速度峰值0.484568rad/s；正常mimic残差0.000408rad，机械臂最终最大参考误差0.007508°，没有持续开口振荡、NaN/Inf或非预期机器人碰撞。两侧作用在物体上的世界合力约[−1.56e-10,3.12e-12,.0981000]N，与10g物体重力平衡，独立验证力坐标变换。

低增益位置控制在物体阻挡时提供有限弹性预载；较重物体/较低摩擦引起滑动、单侧载荷和mimic柔性误差。硬限幅尚未饱和，因此目前优先问题是**低增益/指令范围下的预载、摩擦和柔性mimic受载稳定性**，并非已证明电机硬力矩不足。没有增益整定、改传动约束、虚构惯量或模拟厂家20N力控制来掩盖这些失败。

## 保留的前期失败及修正依据

- 最初窄台/μ=.8配置在倾斜面上持续滑动甚至跌落，不闭合负对照因此不成立。改用18mm宽、μ=1.0、较高接触阻抗的独立支撑台后，不闭合12.5秒保持在台面。没有改变机器人参数或夹指尺寸。
- 原0.5rad/s参考直接闭合产生接触冲击，约1.5–1.6秒就触发mimic保护。改为6秒平滑闭合；不是放宽mimic阈值。
- 初次世界+Z抬升造成倾斜夹爪相对窄台的横向扫掠，9.646秒机器人—台面穿透超过0.1mm并停止。保留其检测；改为沿支撑法向抬升5mm，世界位移约[2.500060,-.003978,4.330090]mm，仍在原10mm工作区和±5°关节界内。
- 约5mm高处直接快速张开触发mimic保护；改慢开仍在落台时出现0.208mm穿透，触发0.2mm保护。没有加厚指垫、改阈值或关闭接触，而是通过机械臂先降近台面再慢开，减小释放落差。5mm直接释放仍属于未通过案例。

所有先导日志及JSON无损gzip归档在outputs/grasp_contact中（first_*、pilot_results、slow_results、slow_release、placed_release），没有删除失败证据。正式results.json/summary.json记录最终配置；失败状态单独保存触发步速度、mimic和接触，避免只看最后一个安全采样点漏掉越界值。
